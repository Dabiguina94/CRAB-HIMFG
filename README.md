# Welcome to CRAB-HIMFG Repository!

This repository contains the raw data generated by the Comparative Genomics analysis of CRAB-HIMFG and AB-DB strains:

- CRAB-HIMFG and AB-DB genome information
- CRAB-HIMFG and AB-DB pangenome presence/abscence annotation
- CRAB-HIMFG strains novel allelic profiles from MLST Oxford scheme 
- CRAB-HIMFG and AB-DB cgSNP distance matrix
- CRAB-HIMFG and AB-DB IS elements mapping
- CRAB-HIMFG and AB-DB plasmids information
- CRAB-HIMFG strains MIC
